# 语言生成结果保留版本与不可变生成条件

日期：2026-11-23

状态：已采纳

语言学习内容可在更换模型、提示词或思考设置后重新生成。只保存模型名称和提示词版本号无法还原当时的请求；覆盖旧结果也无法比较或解释历史作答。

生成使用统一的记录模块。完整实际指令以内容哈希去重，生成记录引用不可变快照，并保存实际输入、模型路线、端点和思考配置。相同输入与目的的尝试归入生成任务，模型和提示词变化不创建新的比较任务。试卷的已有标题排除提示属于生成约束，不属于任务身份。

只有完成并通过功能自身结构校验的结果才能成为候选。新的候选先持久化，再由用户比较选择；取消或无效输出不得替换当前采用。选择及内容关联单独记录。作文反馈、试卷和学习批次保留旧记录；词汇材料修订保持同一义项，并为新的学习证据记录采用的生成版本。

速查结果作为独立历史条目追加，不替换旧条目；重新生成（包括批量操作）直接保存通过校验的新条目，不弹出版本选择。生成记录仍保存实际使用的条件。

旧内容可作为首次比较的原版导入。没有记录的提示词、输入或思考设置保持未知，不从当前设置反推。Mock 不当作真实 AI 生成样本。

完整备份保留所有记录和关联。另提供只读 JSONL 分析导出，包含提示词、请求、结果、采用记录与内容关联；CSV 仅提供比较摘要。导出不包含密钥或私有推理内容。

代价是增加本地存储和迁移工作。相比逐条复制提示词，快照引用减少重复，并确保修改设置不影响已有证据；相比直接替换，保留候选便于用户判断和后续分析。
