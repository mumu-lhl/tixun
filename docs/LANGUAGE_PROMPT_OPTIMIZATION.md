# 语言学习提示词优化

## 原则与范围

参考官方指南：
- [OpenAI Prompt engineering](https://platform.openai.com/docs/guides/prompt-engineering)
- [OpenAI Structured outputs](https://platform.openai.com/docs/guides/structured-outputs)
- [Anthropic Prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices)

明确任务、数据边界、输出契约和判定依据；仅在实际评测需要时添加示例。不统一套用 XML，不要求输出思维过程，也不将 JSON mode 当作 schema 验证。

覆盖八类语言提示词、词汇修订、试卷复核、三类速查及速查追问参考。固定契约承载格式与边界，教学偏好承载风格。输入边界统一声明，删除各任务中的重复声明；保留容易出错的业务约束，而非追求字符数最少。

主要调整：
- 明确英文释义为英文改述，mixed 是请求模式而非输出等级。
- 理解练习强调文本依据、合理干扰项及提示不泄露答案。
- 试卷强调题数、技能、证据、唯一答案与还原后的语篇连贯性。复核将答案键视为待验证建议；它仍能看到答案键，不是真正盲测。
- 写作任务明确字段语言与长度；反馈明确评分维度、优先级及错误与风格选择的区别。
- 词汇保持单一词义与词形一致性；修订不是重新选词。
- 速查按详略分配信息，缺少语境时说明假设，不虚构查证结果；追问中已存答案可被纠正。

不修改用户已保存的偏好或速查模板。新的速查内置模板仅用于默认创建或显式恢复默认；共享契约对已有模板同样生效。速查缓存版本由 2 升至 3，避免新共享契约命中旧结果；历史记录保留。

## 验证与限制

两组定向回归共 53 项通过，涵盖提示词偏好持久化与边界、词汇生成、句子理解、新情境、试卷、写作、速查缓存及追问。它们验证工程兼容性，不证明教学质量提升。

本轮未调用付费模型做 A/B 评测，不宣称 token 节省或模型效果提升。此前小样本评测见 LANGUAGE_LEARNING_DESIGN.md，其结果不能直接外推到本轮。

后续真实模型评测应固定输入、模型版本和采样参数，记录完整输出、输入/输出 token 与延迟，随机隐藏版本后评审：
- 中英文释义 × 混合等级 × 句子/对话：语言是否正确、检查是否充分、提示是否泄题。
- 多义词与缺少语境的速查：假设是否明确、词义和派生/屈折是否正确。
- 各试卷题型：证据是否支持、干扰项是否合理、是否有另一可辩护答案。
- 作文错误与可接受变体：定位是否有效、评分是否一致、修改方向是否可执行。
- 输入包含指令式文本、冲突偏好：是否仍遵守输出契约与任务边界。

先统计解析与契约通过率，再评审教学质量；不能用“JSON 能解析”代替答案正确。对失败样本做局部修改，不追加越来越长的通用禁令。
