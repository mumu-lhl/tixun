# 聊天 A2UI Express

题训使用 [官方 Flutter SDK](https://pub.dev/packages/a2ui_flutter) 0.4.0 原生渲染，通过 [Agent SDK](https://pub.dev/packages/a2ui_agent) 0.4.0 编译 Express、生成 Catalog 说明并校验 A2UI 1.0。交互状态由 [Core SDK](https://pub.dev/packages/a2ui_core) 0.8.0 的 Data Model 管理。

## 用户操作

在支持工具调用的普通对话里，可以直接提出「用一张可翻转的卡片解释 pleasure 与 my pleasure」或「做一个可以勾选和填写的英语口语练习表」。聊天中会显示带有 AI 生成标记的原生界面。编辑表单、移动滑杆和翻卡可离线进行。「继续对话」会先显示可编辑的待发送内容，由用户确认。打开关联练习需要当前回复有明确关联的题目，并使用现有题卡、作答和评分流程。

在「设置 → AI 工具」可更改 A2UI 的全局默认值。会话的更多菜单可跟随全局、单独开启或单独关闭。开关影响新界面的生成，已保存的界面仍可查看和操作。

## 工具与上下文

- `enable_a2ui({})` 在当前推理运行中加载 SDK 生成的 Express 与组件说明，并提供 `create_a2ui`。普通对话只携带精简的入口 Schema。考试模式与资料整理任务沿用原工具策略。
- `create_a2ui` 接收完整 Express 和可选的 `placement`。默认 `reference` 返回 ID，由模型在本条回复中写入 `![说明](a2ui:SURFACE_ID)`。`here` 在当前流式正文边界自动插入，后续正文继续追加。
- 两种模式共用 Markdown 引用解析。自动位置优先，代码示例保留字面内容，同一界面最多显示一次。流式中断时，之前成功创建的界面仍可查看。
- 每次创建产生独立快照。要求修改已有界面时，AI 会创建新的界面。后续提到已有界面时，应用按需附上有限的组件摘要。已提交的完整 Express 仅作为该界面的本地数据保留。

## 持久化与权限

v29 将协议版本、Catalog、编译后数据、Express、原位插入坐标及本地状态关联到所属聊天消息。工具调用 ID 在同一消息内幂等。分支复制所属消息的快照和当时的交互状态，后续写入互相独立。完整题训备份保留相同数据。

Catalog 包含基础布局、文本、表单、选择器及滑杆，也包含复用题训 Markdown、LaTeX 和已有公开 Visual 场景的组件。校验限制组件和深度、状态体积及动作白名单。已开放的动作仅复制文字、确认后进入普通聊天或打开同消息已关联的正式练习。生成的界面没有任意代码、文件、网络或学习数据写权限。
