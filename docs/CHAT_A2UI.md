# 聊天 A2UI Express

题训用官方 `a2ui_agent` 0.4.0 编译 Express，通过 `a2ui_core` 0.8.0 校验 A2UI 1.0 协议，使用 `a2ui_flutter` 0.4.0 原生渲染。[官方 Dart SDK 文档](https://pub.dev/documentation/a2ui_agent/latest/)

## 普通绘图和界面

「设置 → AI 工具」提供 A2UI 与 AI 绘图开关，会话的更多菜单可以覆盖各自的全局默认值。两个开关都开启时，可以问「画出 \(y=x^2\) 的图像」或「用滑杆演示系数改变后抛物线如何变化」。普通绘图可以通过支持文本生成的模型完成。

模型在回复中直接输出完整的 `<a2ui>…</a2ui>` 块，应用分配内部 ID，按正文顺序编译、保存和显示。Markdown 代码中的示例保持字面内容。绘图组件表达函数、数轴、坐标几何和向量语义，客户端用 Visual DSL 的采样、校验和渲染引擎计算视图。函数参数可以绑定 A2UI 滑杆，调整留在本地。翻卡、表单、复制和确认后继续对话也沿用同一 Surface 系统。

## 快照和可复用图形

完整块经过后台编译及质量校验，与回复位置在同一事务提交。半截或失败的块显示降级提示，已成功保存的界面继续可用。数据库沿用 v29，旧工具时代的自动插入和 Markdown 引用仍可读。离线恢复复用内存和数据库中的原有快照，聊天分支独立保存交互状态。

普通图形可以确认后保存为正式图形。同一快照中的同一组件重复保存会复用原有资产，且原界面布局和交互状态独立保存。复杂视觉资产、知识关联和动画仍使用 Visual 工具并维护版本。对当前会话中单个明确引用的小型正式图形，应用会补充必要的结构数据。`get_visual` 继续处理大图、指定修订及无法确定的目标。考试题面图和解析图仍由 `create_quiz` 分开保存。

## 比较和验证

同一抛物线的固定夹具，以题训内置 DeepSeek v4 和 o200k 分词器计数。提示成本只包含绘图相关的额外说明和工具定义，排除公共教学提示、历史、协议封装和服务端缓存。完整 Visual 工具启用后，老路径会在后续请求中继续携带它们。

| 指标 | 原 Visual 工具路径 | 正文 Express |
| --- | ---: | ---: |
| 模型请求轮次（固定流程） | 3 | 1 |
| 绘图相关首轮附加 Token | 117–121 | 372–378 |
| 加载完整 Visual 工具后的附加 Token（每轮） | 14,705–15,698 | 无需加载 |
| 样例图形的生成内容 Token | 65–66 | 32 |

固定夹具核对函数奇点分段、无定义区间、数轴开闭端点、几何顶点和向量方向。客户端 Express 编译比验证已有 DSL JSON 多一步，因此移到后台 isolate。以上对比来自本地夹具，真实模型的延迟、生成成功率和数学正确率仍需实测。
