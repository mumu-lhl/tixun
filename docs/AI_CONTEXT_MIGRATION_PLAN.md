# AI 会话上下文

已实现于数据库 schema v21。界面消息继续负责展示，模型上下文记录在独立的 `chat_context_events` 表中。设计参考 Pi 的有序会话记录，不复制其文件格式或厂商协议。

## 写入和重放

- `features/chat/chat_context_store.dart` 按界面消息和轮次保存已发送用户文本（含当时的应用上下文）、附件 ID、指令及工具定义的变化、已完成的助手输出及完整工具结果。附件仍由本地附件 Store 管理，不在事件中保存 data URL。
- 下一轮按同一消息顺序重建上下文。已保存的用户内容保持稳定，最新学习状态附在新用户输入上。当前指令、工具、权限和模型能力仍以当前设置为准，历史快照不授予权限。
- 只有正常完成且与当前模型、传输、教学模式、资料和绘图授权等相符的历史轮次，才会重放工具上下文。未完成、当前不允许和含私密测验数据的轮次退回界面历史。重放只构造请求，不执行历史工具。Responses 加密推理上下文只在当前运行的内存中存在；API Key 和 OAuth 凭据仍由系统安全存储处理。
- 旧会话保留界面历史，不补造工具调用或过去发送的动态上下文。应用级记录不等同于逐字节 HTTP 抓包，也不包含服务商隐藏状态。

## 压缩、分支与备份

- 预算计入可重放的工具上下文，按完整轮次选取后缀。摘要只引用界面可见会话，不复制隐藏工具结果。摘要和覆盖位置作为检查点保存，原始事件保留；后续请求把摘要放在用户级历史资料中，而非系统指令。
- 分支复制到所选消息为止，重映射消息和附件引用，仅复用完整落在分支里的检查点。编辑分支起点重新记录输入，原分支保持不变。
- 废纸篓保留可恢复的会话；永久删除级联清理事件。完整备份包含本机模型上下文，界面已说明可能包含提示词、学习背景和工具结果。恢复仍按现有规则关闭资料工具。

## 验证与边界

回归覆盖重启后的请求前缀和工具序列、撤权和中断、图片分支与删除、完整轮次压缩、迁移及备份恢复。同一配置下保留旧输入有助于稳定前缀；修改系统提示词、切换工具集或重做摘要仍可能使前缀失效。未实测真实服务商的缓存命中率，不能据此判断此前约 50% 命中率的成因。

用量统计独立保存在 `ai_usage_events`。本地 tokenizer 按每次请求统计应用可见文本，只存数字；协议开销、图片及服务商隐藏思考不计入，不代替计费或缓存用量。
