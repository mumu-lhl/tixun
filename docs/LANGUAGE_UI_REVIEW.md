# 语言学习 UI / 交互审查

本轮是代码与局部 widget 测试审查，不代表 Android/Linux 真机、键盘、屏幕阅读器和全部学习流程验收。

## 已处理

- 学习首页：时间线、考试与语言学习入口使用同一行布局，窄屏统一换行，不再混用居中与左对齐。
- 语言首页：考试推荐、模拟考试改为列表入口，专项训练收进展开列表，减少同权重按钮堆叠。
- 快捷任务管理：限制内容宽度；启用状态改为可见开关；加载失败可重试；恢复默认先确认。
- 快捷任务编辑：默认展示名称、任务指令、目标语言和启用状态；图标、说明、输入占位、输入语言、解释语言和详细输出收进高级选项，折叠后保留编辑。指令与验证错误始终在主表单中。取消或系统返回时确认丢弃更改；提示词显示 token 估算。
- 提示词设置：列表、编辑、预览各块显示当前模型的 token 估算。支持的模型使用本地词表；其他模型回退粗估。文本计数不包含请求封装、工具、缓存计费等，不能视为服务商账单。输入合并 250ms 内的更新，避免每次重建启动计数。
- 知识/错题新建：按学科选择模块，路径显示父级；保存与关联在同一事务中完成。切换学科清空选择，最多 20 个模块。新建与详情页共用可搜索选择器，新建表单只显示已选摘要，可移除选择；选择器内可管理目录，返回后实时更新，不丢弃其他选择。
- 词汇编辑：取消与系统返回均检查未保存修改；取消丢弃后保留输入，保存中禁止退出。
- 空白章节不再作为新建表单中的另一套分类要求；已有章节仍可查看/编辑，避免破坏历史数据。
- 语言首页：推荐练习作为主操作，进入画像推荐；复习、语境与造句作为次级操作。英语学习区保留英语标题，基础课程入口明确为“多语言入门课程”。
- 考试题库、写作任务、画像、首页词汇组与学习证据：共用读取失败与重试组件，只重新订阅读取，不重建页面，保留页面筛选及输入状态。首页到期复习计数也可手动重试。

## 仍需解决（按优先级）

### P2：导航与反馈缺少一致性

- 词汇、造句、考试、写作的布局宽度与流程容器尚不统一。统一布局后仍要逐页验证长译文、反馈展开、大字体、软键盘遮挡与窄屏操作区，不能只靠静态代码检查判断。

## 分类模型的边界

模块应是新的组织入口，不再要求手输章节作为平行目录。不过旧章节可能是文本标签，不一定唯一对应一个模块；学习范围也可能是一次练习的临时过滤条件，不能不加区分全部删除。本轮没有删数据库字段或自动将章节迁移成模块。后续迁移应提供映射与兼容读取，并检查搜索、导入导出和 AI 工具契约。

## 验证与待验收

已运行 tokenizer 参考值、模块存储、新建知识/错题模块关联、提示词设置、学习页入口及快捷查询 360/1200 宽度的定向测试。补充验证了词汇编辑取消/返回的丢弃确认，以及两个宽度下快捷任务指令验证、高级选项折叠保留修改及保存。读取重试组件覆盖同步抛错、流异步错误、重试恢复与外围输入保留；首页主入口在两个宽度下有回归断言。考试与写作存储行为回归通过。仍需真机检查快捷任务编辑的返回/重置、长列表、语言首页展开导航及可访问性；不将这些未验证项标为通过。
