# 语言学习 UI / 交互审查

本轮包含代码审查、定向 widget 回归及 Linux 原生窗口集成测试与截图检查；不代表 Android 真机、真实软键盘、屏幕阅读器及全部学习流程验收。

## 已处理

- 学习首页：时间线、考试与语言学习入口使用同一行布局，窄屏统一换行，不再混用居中与左对齐。
- 语言首页：考试推荐、模拟考试改为列表入口，专项训练收进展开列表，减少同权重按钮堆叠。
- 快捷任务管理：限制内容宽度；启用状态改为可见开关；加载失败可重试；恢复默认先确认。
- 快捷任务编辑：默认展示名称、任务指令、目标语言和启用状态；图标、说明、输入占位、输入语言、解释语言和详细输出收进高级选项，折叠后保留编辑。指令与验证错误始终在主表单中。取消或系统返回时确认丢弃更改；提示词显示 token 估算。
- 提示词设置：列表、编辑、预览各块显示当前模型的 token 估算。支持的模型使用本地词表；其他模型回退粗估。文本计数不包含请求封装、工具、缓存计费等，不能视为服务商账单。输入合并 250ms 内的更新，避免每次重建启动计数。
- 知识/错题新建：按学科选择模块，路径显示父级；保存与关联在同一事务中完成。切换学科清空选择，最多 20 个模块。新建与详情页共用可搜索选择器，新建表单只显示已选摘要，可移除选择；选择器内可管理目录，返回后实时更新，不丢弃其他选择。
- 词汇编辑：取消与系统返回均检查未保存修改；取消丢弃后保留输入，保存中禁止退出。
- 空白章节不再作为新建表单中的另一套分类要求；已有章节仍可查看/编辑，避免破坏历史数据。
- 语言首页：推荐练习作为主操作，进入画像推荐；复习、语境与造句作为次级操作。英语学习区保留英语标题，基础课程入口明确为“多语言入门课程”。
- 考试题库、写作任务、画像、首页词汇组与学习证据：共用读取失败与重试组件，只重新订阅读取，不重建页面，保留页面筛选及输入状态。首页到期复习计数也可手动重试。

- 词汇、造句、试卷、写作练习使用统一的自适应滚动容器，最大内容宽度 760，窄屏边距与其他语言页面一致。
- 写作反馈请求及保存期间阻止返回；未保存输入退出前确认，取消丢弃保留输入。回归测试恢复旧退出条件后会失败，修复后通过。
- 写作版本历史、写作批注和试卷答题历史读取失败可重试，不再静默隐藏错误。

## 本轮布局验证

`test/features/language_learning/language_practice_layout_test.dart` 覆盖 360/1200 宽度、1.6 倍字体、长写作任务、长译文与提示展开、词汇语境作答反馈；写作及试卷输入模拟 300 高度键盘遮挡并滚动到输入框。另覆盖写作丢弃取消和等待反馈时系统返回。键盘遮挡使用测试窗口 inset，并非 Android 输入法。

`integration_test/language_practice_flow_test.dart` 在 Linux 原生窗口复用上述流程，截图位于 `artifacts/gui-language/`。已检查窄屏四页面与宽屏写作、试卷截图；无布局异常。题目来自测试夹具，不调用收费服务。该测试不覆盖服务商真实响应和全部主页导航。

## 验收阻塞与限制

- 当前 `flutter devices` 只有 Linux 和 Chrome，没有 Android 设备或模拟器；Android 实机软键盘、系统返回与 TalkBack 尚不能验收。
- 未完成 Linux 屏幕阅读器及完整键盘焦点遍历。不能将自动测试无溢出等同于可访问性验收。
- 快捷任务返回/重置、完整主页导航等已有定向测试，但未将全部组合逐一进行原生端人工验收。

## 分类模型的边界

模块应是新的组织入口，不再要求手输章节作为平行目录。不过旧章节可能是文本标签，不一定唯一对应一个模块；学习范围也可能是一次练习的临时过滤条件，不能不加区分全部删除。本轮没有删数据库字段或自动将章节迁移成模块。后续迁移应提供映射与兼容读取，并检查搜索、导入导出和 AI 工具契约。

## 验证与待验收

已运行 tokenizer 参考值、模块存储、新建知识/错题模块关联、提示词设置、学习页入口及快捷查询 360/1200 宽度的定向测试。补充验证了词汇编辑取消/返回的丢弃确认，以及两个宽度下快捷任务指令验证、高级选项折叠保留修改及保存。读取重试组件覆盖同步抛错、流异步错误、重试恢复与外围输入保留；首页主入口在两个宽度下有回归断言。考试与写作存储行为回归通过。新增练习布局及写作退出回归，并在 Linux 窗口运行同一测试套件；未验证项见上方验收限制。

## 词汇组与生成版本

词汇组移入语言学习的子页，组卡片菜单提供添加、AI 扩充和删除；底部固定学习/练习切换。创建组共用空组与 AI 填充入口，AI 填充时允许留空组名。同名组保存前提示加入或修改名称；组内排除词由完整组内容决定，本地去重不依赖发送给模型的有限排除提示。

识字卡的上一张、下一张和随机导航固定在底部并保留间距，卡片高度不移动导航区域。例句只对完整目标词、短语及已保存词形添加强调色和细下划线。译文和词形操作采用相同按钮样式。

AI 生成记录与分析导出见 [生成版本决策](adr/0001-language-generation-history.md)。历史数据缺失的生成配置保持未知。

新情境理解使用词汇组中的词汇生成完整的新场景，让用户选择意思或用法，不提供填空。旧例句挖空材料不进入新入口，历史数据保留。新增回归覆盖拒绝重复例句及空缺场景、直接显示理解选项和作答结果。

本轮检查了 320/1200 宽度、1.6 倍文字的真实字体 widget 渲染截图：词汇组、创建组、菜单、识字卡、新情境理解与生成比较；另检查高级图标选择器在展开边界内完整显示浮动标签。截图保存在本地 `artifacts/language-ui/`，不是设备截图。未调用真实 AI 服务，生成契约及选择流程由响应夹具验证。
