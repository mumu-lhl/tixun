# 词汇闪卡 FSRS 调研与验收标准

2026-11-25

## FSRS 解决的问题

FSRS 根据同一张卡片的回忆评分和两次评分之间的间隔，更新记忆稳定性和难度，再按期望保持率估算下次复习时间。FSRS-6 的稳定性以天计，表示预估回忆概率降到 90% 所需的时间。期望保持率是模型在安排复习时采用的目标。提高目标通常会增加复习量。词汇组的每轮上限、到期词和新词的排序、同轮重练如何出现，属于应用的队列规则。[FSRS-6 算法说明](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm#fsrs-6) · [Anki 牌组选项](https://docs.ankiweb.net/manual/deck-options#desired-retention)

## 研究证据与适用范围

| 证据 | 发现 | 能支持的结论 |
| --- | --- | --- |
| 间隔学习的元分析 | Cepeda 等汇总了 184 篇文献、317 项实验、839 个比较，发现适合的练习间隔随目标保持时间而变，目标保持越久，最佳间隔通常越长。 | 支持把词义回忆安排在不同时间。比较对象是间隔策略，研究早于 FSRS。 [Cepeda 等，2006](https://www.yorku.ca/ncepeda/publications/CPVWR2006.html) |
| 外语词汇的提取练习实验 | Karpicke 与 Roediger 让学生学习斯瓦希里语与英语词对。初次正确后，继续提取提高了一周后的回忆表现。实验未观察到继续学习这些词对能改善延迟回忆。 | 支持先回忆再翻卡、通过延迟回忆衡量学习效果。 [Karpicke 与 Roediger，Science 2008](https://profiles.wustl.edu/en/publications/the-critical-importance-of-retrieval-for-learning/) |
| 自适应选题的随机对照 | Upadhyay 等在约 50,700 名德国驾照笔试学习者中随机分组。与随机选题和仅按难度选题相比，研究所用的机器学习序列在控制练习长度与频率后表现出更慢的遗忘，作者摘要估计记忆持续时间约长 69%。 | 随机分组为自适应选题提供了因果证据。试验使用驾照题和 SELECT 算法，69% 是该研究的估计。 [Upadhyay 等，npj Science of Learning 2021](https://doi.org/10.1038/s41539-021-00105-8) |
| 语言平台的回放与上线实验 | Settles 与 Meeder 用约 1,290 万条学生—词汇记录评估 HLR，论文摘要报告预测误差较多项基线下降 45% 以上。表 4 中常引用的 12% 是不含词汇特征的 HLR 相对含词汇特征版本的每日用户留存增幅，衡量用户是否继续回来学习。Tabibian 等独立分析 Duolingo 日志，发现实际练习顺序更接近其 MEMORIZE 调度的记录对应较慢遗忘。后者是按既有行为归组的自然实验。 | 支持将预测准确度、用户使用和延迟回忆分别报告。这些实验采用 HLR 或 MEMORIZE。 [Settles 与 Meeder，全文 §4 与表 4](https://aclanthology.org/P16-1174.pdf) · [Tabibian 等，PNAS 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6410796/) |
| 词汇调度模拟 | Ye 等用约 2.2 亿条墨墨词汇记录建模。在相同每日成本的模拟中，SSP-MMC 达到指定总半衰期目标需 466 个模拟日，阈值调度需 533 日，相差 12.6%。 | 说明模拟可以比较复习量与长期记忆目标的取舍。结果依赖模拟记忆模型、成本和目标设定。 [Ye 等，KDD 2022 §5.3](https://www.maimemo.com/paper/) · [复现实验](https://github.com/maimemo/SSP-MMC) |
| FSRS 的回忆概率预测基准 | Open Spaced Repetition 用 Anki 日志按时间划分训练和测试。在约 9,999 个用户集合、3.499 亿条用于该分析的复习记录、仅以非当日复习作为该表预测目标的口径下，FSRS-6 的 log loss 为 0.3460，FSRS-5 为 0.3561，FSRS-7 为 0.3401。FSRS-7 默认参数的独立条目为 0.3620。这个基准由算法相关团队维护。 | 支持 FSRS 对真实日志的回忆概率有预测能力。训练配置、评价样本和指标都会影响结论。按旧排程产生的日志无法直接对比换用新排程后的学习效果，且该 FSRS-6 数字来自训练参数的版本。 [SRS Benchmark 固定快照](https://github.com/open-spaced-repetition/srs-benchmark/blob/57c0b0700c8a63cc7b68ffb9c8270271db8fd021/README.md#result) |

本次检索未找到足以估计题训收益的 FSRS-6 对照试验。题训与上述研究的实际间隔、题型和自评方式都可能不同。预上线适合先核对评分与调度，后续用真实的延迟、无提示回忆和复习开销衡量收益。

## Flutter 实现候选与边界

- `fsrs` 2.0.1 是 Open Spaced Repetition 发布的 MIT 许可纯 Dart 包，支持 Dart ^3.3.0。2.0.0 引入 FSRS-6，2.0.1 修复与 Flutter SDK 测试依赖的兼容问题。发布包可用 `Scheduler.reviewCard` 计算新状态及到期时间。它要求显式传入的评分时间用 UTC，内部按经过的完整 24 小时数计算间隔。需要在应用中明确日界线和时区的语义。 [pub.dev 2.0.1](https://pub.dev/packages/fsrs/versions/2.0.1) · [变更记录](https://pub.dev/packages/fsrs/changelog) · [Dart 实现源代码](https://github.com/open-spaced-repetition/dart-fsrs/blob/cd3df9cc5e3021be4940fa2c7b9aa46ce99a565b/lib/fsrs.dart#L581)
- 同是 FSRS-6，不同来源的默认权重已核对有差异。Dart 2.0.1 的前四项为 `0.2172, 1.1771, 3.2602, 16.1507`，项目公式页的前四项为 `0.212, 1.2931, 2.3065, 8.2956`。Dart 包的构造默认值还启用 1 分钟、10 分钟学习步骤，10 分钟重学步骤以及间隔随机扰动。参考向量必须标记参数来源，并按同一权重和调度设置校验。 [发布包归档](https://pub.dev/api/archives/fsrs-2.0.1.tar.gz) · [FSRS-6 默认参数](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm#default-parameters) · [Dart Scheduler 构造函数](https://pub.dev/documentation/fsrs/2.0.1/fsrs/Scheduler/Scheduler.html)
- `fsrs-rs-dart` 有底层 FSRS 内存状态及间隔接口，也有封装学习步骤的调度器。它要初始化 Rust bridge，并引入针对 Android 和 Linux 的原生构建。纯 Dart 包适合先做独立参考向量验证，Rust 绑定是以后需要共享 Rust 库或扩展时的候选。FSRS-7 已有公开规格和预测基准，以上 Dart 发布包实现的是 6，跨版本需要独立核对持久化状态和算法。 [Rust Dart 绑定](https://github.com/open-spaced-repetition/fsrs-rs-dart) · [FSRS-7 规格](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm#fsrs-7)

在隔离环境中，将 Dart `fsrs` 2.0.1 与 Py-FSRS 6.3.3 按相同输入运行。两者使用 Py-FSRS 6.3.3 的 21 个默认权重、0.90 目标保持率、空学习和重学步骤、关闭间隔扰动、180 天间隔上限。新卡在 2026-01-01 00:00 UTC 的四个首次评分结果一致。随后分别以新卡的 Good 结果为起点计算两个 Hard 场景。72 小时后，稳定性都为 9.23487078 天，到期日均为 1 月 13 日，难度分别为 4.75863012 和 4.75285849。12 小时后，稳定性分别为 1.33337872 和 2.3065 天，到期时间分别为 1 月 2 日 12:00 和 1 月 3 日 12:00 UTC。

源码显示，Dart 对难度均值回归使用已经裁限的初始 Easy 难度，也缺少 Py-FSRS 为成功的同日 Hard 评分保留原稳定性的下限。未经修正的 2.0.1 未通过该参考实现的一致性检查。首次评分碰巧一致不足以验证后续日程。选库时应以固定权重和独立测试向量为准。 [Dart 递推源码](https://github.com/open-spaced-repetition/dart-fsrs/blob/cd3df9cc5e3021be4940fa2c7b9aa46ce99a565b/lib/fsrs.dart#L869-L931) · [Py-FSRS 6.3.3 递推源码](https://github.com/open-spaced-repetition/py-fsrs/blob/v6.3.3/fsrs/scheduler.py#L697-L728)

## 题训现状与建议范围

「词义回忆」就是词汇组「练习」里的闪卡流程。先看单词或固定表达，自己回想这张卡对应的释义，再翻卡自评。「单词练习」还包括选释义、词形和用法等练法。首版 FSRS 接入词汇组闪卡和语言页的到期复习，按每张卡的义项安排日程。[词汇组练习入口](../lib/features/language_learning/vocabulary_groups_screen.dart) · [闪卡流程](../lib/features/language_learning/vocabulary_batch.dart)

升级前词汇组回忆按义项录入顺序分页，语言页到期队列也包含新建义项。四档自评通过固定天数或倍数修改间隔，同日重练也可能改动到期日或重复次数。旧证据包含义项、评分、时间、组提示及关联的生成版本，但无法可靠区分所有历史重练，也无法判断用户选「模糊」时是否回忆出了核心释义。[练习流程](../lib/features/language_learning/vocabulary_batch.dart) · [队列与调度](../lib/features/language_learning/language_store.dart) · [证据和调度表](../lib/core/database/language_tables.dart)

建议首版用 FSRS-6 为每个义项计算下次到期时间，再由题训决定词汇组内本轮出哪些卡。参考 Py-FSRS 6.3.3 的 21 个默认权重。首版离线运行，关闭间隔随机扰动，由现有的同轮重练处理短间隔练习。个性化权重拟合与手动编辑权重、历史评分全量重算、其他练习技能和通用复习算法留待后续。[Py-FSRS 6.3.3](https://github.com/open-spaced-repetition/py-fsrs/tree/v6.3.3)

旧卡保留已排的时间。既往已评过的义项在第一次符合新规则的评分时初始化 FSRS，并和真正的新词分别计入统计。这样旧记录仍可查看，也能单独观察首次切换时的保守间隔对负担的影响。词汇组语境会给出线索，组内正式评分可以更新同一义项日程，但必须保留有组提示的标记。检验算法效果时以无组提示的延迟测试为主。

### 复习设置

在语言学习设置里提供一套词汇闪卡的复习设置。词汇组、全部词汇和到期复习共用这套设置，同一义项加入不同组时仍使用同一份日程。每轮词数继续从词汇组练习设置调整。FSRS 默认关闭，可手动启用试用。关闭后沿用已排好的日期，下一次正式评分使用旧间隔规则。

| 用户设置 | 首版取值 | 教学与界面说明 |
| --- | --- | --- |
| 目标记忆率 | 默认 90%，可设 70%–97%，步长 1 个百分点。 | 到期时希望能想起卡片的概率。值越高，复习通常越频繁。实际回忆率需单独测量。 |
| 最大复习间隔 | 放在高级设置。默认 180 天，允许 1–36,500 的整数天。 | 两次正式复习可相隔的天数上限。缩短上限通常会增加复习量。180 天沿用题训旧调度的最长间隔。 |

设置保存或恢复默认值后，从下一次正式评分开始使用新值。已有到期日保留，当前轮的卡片列表继续按开轮时的队列展示。设置按本地用户保存，重启和备份恢复后继续生效。取值范围为题训首版方案，Anki 的设置用作参照。[Anki 的目标记忆率](https://docs.ankiweb.net/deck-options.html#desired-retention) · [最大间隔](https://docs.ankiweb.net/deck-options.html#maximum-interval) · [修改设置时的重排策略](https://docs.ankiweb.net/deck-options.html#reschedule-cards-on-change)

## 首版实现验收

以下每项都有对应的通过条件。用固定时钟建立可重复的队列与评分测试，用真实数据库和页面补齐写入、升级和交互验证。

| 项目 | 通过条件 | 验证方式 |
| --- | --- | --- |
| 算法一致性 | 实现与默认权重均锁版本。用 Py-FSRS 6.3.3 的默认权重、90% 目标记忆率、180 天上限、空学习与重学步骤、关闭随机扰动生成参考向量。覆盖四种首评、正常复习、同日与跨天的 Hard、提前与逾期输入、遗忘后跨天再次回忆以及触及间隔上限。稳定性与难度的绝对误差各不超过 `1e-6`，离散间隔和到期时间与参考值一致。夹具记录生成指令和输入。 | 纯 Dart 单测与固定上游夹具 |
| 用户设置 | 新安装及旧备份缺字段时使用 90% 和 180 天。允许两个参数的边界值，拒绝越界和非法输入并保留上次有效设置。设置可恢复默认值，重启和备份往返保持所选值。保存与重置时验证已有到期日及本轮队列原样保留。固定同一状态和评分，在不触及上限的夹具中提高目标记忆率会缩短间隔，降低上限会截断较长的间隔。分别验证词汇组及全局到期复习的下一次正式评分使用保存值。 | 双语设置组件测试、数据库往返、两条入口的端到端测试与非默认参数参考向量 |
| 四档语义 | 展开释义后显示「没想起来／费力想起／想起来了／轻松想起」或同义中英译文，依次映射 `Again / Hard / Good / Easy`。只想起碎片、核心义项不完整时选第一档。评分说明可在评价时查看，保留两行等宽与独立跳过入口。 | 双语组件测试和 Android、Linux 页面验收 |
| 证据边界 | 浏览、仅展开、跳过和退出均不生成自评或改变到期时间。同轮重练、明确选择的自由练习写入可区分的练习记录，均不改变模型状态、上次正式复习时间和到期日。识别、造句和新情境理解继续使用各自的证据。 | Store 状态差异测试和页面流程测试 |
| 词汇组选词 | 冻结本轮选卡时间与队列。只取当前组、当前语言，优先取已做过且到期的义项，按到期时间升序，同一时间用义项 ID 排序；余位放未评的新义项，按录入时间和义项 ID 排序。未来到期的旧词不自动补位，可从单独的「自由练习」入口练习。已选的每轮词数设为上限，遵守现有偏好；合格卡少于上限时据实显示。 | 固定时钟、跨组及跨语言的队列夹具 |
| 全部词汇 | 词汇组切到「练习」即可选择「练习全部词汇」。从当前语言所有组的义项取并集。同一义项跨组只出现一次，单词的不同义项仍各自安排。排序、每轮词数、续轮、跳过和自由练习规则与单组一致。合并队列不提供单个组的标题提示。 | 固定时钟查询测试和三轮真实页面流程 |
| 翻轮与跳过 | 评价当前卡并使其离开到期集合后，下一轮仍能取到其余原本到期的卡。正常翻轮不重复本次已见义项，不通过对变动的到期队列使用偏移分页。跳过卡本次不自动弹回，另开练习后若仍合格可再次出现。共享义项在不同组使用同一日程，不同义项独立。 | 至少三轮的 Store 和 Widget 测试，含两个组共享义项 |
| 全局到期入口 | 由于「到期」指已评义项到期，语言首页和学习档案采用同一谓词与截止时间，列表和计数一致。未评的新义项由词汇组提供，浏览列表仍按原规则分页。到期边界 `dueAt <= now`；没有合格卡时显示空状态。 | 同一固定时刻比较首页、档案与全局队列，覆盖边界前、等于和边界后 |
| 事务和恢复 | 一次正式评分的记录与日程更新在同一事务；重复使用同一尝试 ID 只生效一次；两个会话抢答同一义项时，后提交者若已不合格就只记录练习，不能再改日程。模拟写入失败后，重试成功只留下一个有效评分及对应状态。应用重启、切换时区或跨夏令时不会偏移已存到期时间。 | 真实 Drift 数据库的并发、故障注入和时钟测试 |
| 升级与备份 | 从发布版数据库升级，义项、组、旧评分和原定到期时间不变。保留旧评分原义，不批量把「模糊」改为 Hard。旧调度允许在首次合格评分时转为版本化的 FSRS 状态。新旧备份恢复后的队列、状态和历史与升级路径一致。 | Drift 显式迁移、旧备份恢复和新数据往返测试 |
| 离线与界面 | 飞行模式下能进入词汇组、评分、重练和续轮。首次正式评分、跳过、全跳过和耗尽队列路径都可完成。320dp、1.6 倍字号及 1200dp 桌面下，评分标签可完整阅读，键盘能选中按钮。用户能分辨「到期」「新词」和「自由练习」。 | Flutter analyze、组件测试和 Android／Linux GUI 验收 |

## 效果验证与默认启用门槛

1. **先检查预测。** 在可取得的、用户同意用于评估的题训记录上，按时间顺序用过去状态预测下一次正式回忆；固定预设及样本纳入规则，再打开保留集。报告 log loss、分箱校准曲线和样本数，按有无组提示、首次使用与旧卡切换分层。旧规则只产出日期，直接和它比较的是学习效果与负担；预测误差应和提供回忆概率的基线比较，例如仅依赖历史成功率及实际间隔的简单模型。
2. **再测真实学习收益。** 工程验收通过即可进入自愿试点。按用户随机分组比较题训旧规则与 FSRS，两组使用同样的评分文案、每轮词数选项与选词规则。FSRS 组从 90% 和 180 天的默认设置起步，记录试点期间的设置变更。试点开始时预选一组词并安排相同的首次学习，以此为统一起点，在第 7 天（允许第 6–8 天）用无组提示、提交前隐藏释义的测试测词义回忆正确率。预先定义可接受的答案，同时记录每位用户的每周复习分钟数、完成次数和退出率，将再次学习的次数计入负担。可增加第 28 天测验补充较长期结果。随机后按原分组分析，报告失访和置信区间。同轮练习的自评分不算延迟测验结果。
3. **先定门槛，再看结果。** 建议默认启用需同时满足三个条件。FSRS 相对旧规则的回忆率差值，其 95% 置信区间下界高于 −3 个百分点。每周复习时间比值（FSRS 组除以旧规则组），其 95% 置信区间上界低于 1.10。至少一个指标显示明确改善，即回忆率差值下界高于 0，或复习时间比值上界低于 1。这些是题训的拟议产品阈值。试点前用基线方差和预计失访确定样本量、观察周期与停止规则。样本不足或未达门槛时保持试点。
